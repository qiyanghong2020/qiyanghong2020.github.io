# Qiyang Hong Personal Website

Source code for <https://qiyanghong2020.github.io/>.

The site is built with Hugo Blox and contains Qiyang Hong's academic profile, selected research projects, publications, experience, and downloadable CV.

## Common Commands

```powershell
pnpm run dev
pnpm run build
```

## Key Content Paths

- `data/authors/me.yaml`: profile, education, experience, skills, and professional activities.
- `content/_index.md`: homepage research summary and selected project overview.
- `content/publications/`: publication records.
- `content/experience.md`: experience, skills, certifications, and professional activities page.
- `static/uploads/resume.pdf`: downloadable CV.
